# EV Charger Security

Talk for the **Car Hacking Village** at **CODE BLUE**, Tokyo, Nov 2026.

A generic tour of the EV-charging attack surface: the cable (Control Pilot,
HomePlug/SLAC), the conversation (DIN 70121 / ISO 15118, TLS, Plug&Charge),
the backend (OCPP, OCPI), and the box itself (Linux SoC, PLC modem, payment).
