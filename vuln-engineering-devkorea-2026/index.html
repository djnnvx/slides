Exploit dev = graph search

Capabilities = nodes. PoCs = hops.

Framing: D. Blazakis, "exploit development is mapping a path through the attacker capability graph". Independently formalised by PrimSynth, arXiv Sep 2026.

1988: nothing in the way

No defenses at all. One bug and you are in. The only wall was the wrong CPU.

E. Spafford, "The Internet Worm Program: An Analysis", Purdue CSD-TR-823, 1988.

2011: defenses force ROP

Code signing blocks any new code. So the whole exploit is built from code already on the phone.

2026: defenses force data-only

Every defense on. The obvious routes are walled off. An agent reroutes without running any code at all.
